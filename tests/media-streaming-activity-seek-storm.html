Nothing else may be streaming in this browser. WebProcessPool::updateMediaStreamingActivity notifies only when its count of processes with media streaming crosses zero, so any other page holding that state keeps the count above zero and every transition this page makes is dropped before it reaches the NetworkProcess. The counters below still fill in, because they come from the ManagedMediaSource events upstream of that gate — so full page-visible churn with no notifications at all means something else is streaming.
